# ORG-003: Restore the existing UI layout

Status: COMPLETE
Team: Lead
Services: Shared UI, Ground Booking, Tournaments

## Request

The user asked to revert the UI layout changes. Restore the prior presentation
and preserve the requested grounds, pricing and payment tracking functionality.

## Changes

- Restore the original sidebar branding, navigation labels, topbar and bottom
  navigation. Remove the global `design.css` inclusion and replacement font
  preload, sidebar promotional card and redundant dashboard header shortcut.
- Restore the original home feed and connections section. Remove the new
  clubhouse hero and restore the existing headings and feed text.
- Restore the original arena-background sign-in and signup presentation while
  keeping organisation signup, recovery and authentication behavior.
- Restore compact ground dialogs and the existing form/card/status styles.
  Show costs as ordinary detail rows instead of new payment cards or grids.
- Remove the large financial dashboard panel. Keep totals in a collapsed
  `Payment totals` disclosure within the existing overview sidebar card.
- Preserve money snapshots, quote validation, booking questions, owner payment
  recording, cancellation/refund tracking and deposit returns.
